# Documentation

Documentation lives in this folder and is versioned with the code. It is written in English.

## Planned structure

- `user/` : user guide (install, sources, playback, profiles, parental control), remote app guide, FAQ, troubleshooting, accessibility features.
- `extensions/` : extension developer guide (API, structure, permissions, lifecycle, publishing, full tutorial).
- `technical/` : architecture, data model, library and recognition rules, playback, extensions and themes, control API, mobile app, operations (packaging, CI/CD, accessibility audit, performance measurements).
- `adr/` : architecture decision records.
